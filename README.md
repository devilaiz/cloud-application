# Cloud Application

Учебный проект по дисциплине «Управление работами и разработка программного обеспечения облачных систем».
Проект предназначен для изучения серверной разработки и программного обеспечения облачных систем.

## Возможности
- Серверное приложение FastAPI;
- Модульная архитектура (routers, schemas, services, data);
- REST API для управления облачными сервисами;
- Валидация состояний сервисов (`running`, `maintenance`, `stopped`);
- Фильтрация сервисов по статусу;
- Автоматическая интерактивная документация OpenAPI (Swagger UI / ReDoc).

## Структура проекта
- `app/routers/` — маршрутизаторы HTTP-запросов (services, system);
- `app/schemas/` — Pydantic модели и схемы данных;
- `app/services/` — бизнес-логика приложения;
- `app/data/` — хранение данных;
- `PROJECT_TASKS.md` — backlog и задачи проекта.

## Состояния сервисов
Для облачных сервисов поддерживаются следующие состояния:
- `running` – сервис работает;
- `maintenance` – сервис находится на обслуживании;
- `stopped` – сервис остановлен.

## Работа с проектом
Изменения проекта выполняются в отдельных Git-ветвях и после проверки объединяются с основной ветвью `main`.

## Основные адреса
- `/` — основная информация;
- `/status` — состояние приложения;
- `/about` — информация о сервере;
- `/course` — данные об учебном курсе;
- `/service-count` — общее количество сервисов;
- `/services` — управление и фильтрация сервисов;
- `/docs` — интерактивная документация Swagger UI;
- `/redoc` — документация ReDoc.

## Инструкция по запуску в VS Code

1. Распакуйте архив и откройте папку проекта в Visual Studio Code (`File -> Open Folder`).
2. Откройте встроенный терминал (`Terminal -> New Terminal`).
3. Создайте и активируйте виртуальное окружение:
   ```powershell
   python -m venv .venv
   .venv\Scripts\Activate.ps1
   ```
4. Установите зависимости:
   ```powershell
   pip install -r requirements.txt
   ```
5. Запустите сервер локально:
   ```powershell
   python -m uvicorn app.main:app --reload
   ```
6. Перейдите в браузере по адресу: [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)
