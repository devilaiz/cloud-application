# Cloud Application

## Этап развития
Фильтрация и контроль состояния облачных сервисов.

## Требования
- **REQ-01**: API должно поддерживать получение списка сервисов по состоянию (`status`).
- **REQ-02**: Для поля `status` должны допускаться только значения: `running`, `maintenance`, `stopped`.
- **REQ-03**: При отсутствии параметра фильтрации API должно продолжать возвращать полный список сервисов.
- **REQ-04**: Документация API должна содержать новую возможность фильтрации и допустимые значения состояния.
- **REQ-05**: Поиск и валидация данных сервисов должны быть оптимизированы для надежной работы REST API.
